# ☕ Brew Haven Coffee Shop

A modern and responsive coffee shop website built using HTML, CSS, JavaScript, and Bootstrap.

## 🚀 Features

- Responsive design
- Animated hero section
- Coffee menu
- Shopping cart UI
- Gallery
- Contact form
- Dark mode
- Smooth animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5

## 📂 Project Structure

```
Brew-Haven/
│── index.html
│── about.html
│── menu.html
│── contact.html
│── css/
│── js/
│── images/
```
